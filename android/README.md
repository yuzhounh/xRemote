# xRemote Android

一个 APK 内集成 EasyTier 私网连接与 FreeRDP 远程桌面，显示10个设备入口：9条RDP、1条VNC。清单包含家里电脑、两台办公室电脑、三台服务器、ThinkPad T530的Windows与Ubuntu、ThinkPad X1 Carbon和MacBook Pro。VNC通过内嵌AVNC 3.3.1 / LibVNCClient直接显示和控制Mac屏幕，支持点击、拖动、长按右键、缩放、键盘及Mac快捷键。连接使用Mac屏幕共享的VNC密码，保存在既有Android Keystore加密存储中。

版本与桌面面板一致。构建从 `../Ui/AppVersion.cs` 读取 Major、Minor、Patch 和 ForkRevision；当前显示 `1.3.0 Rev.23`，Android versionCode 为 103000023。本轮手机仅同步版本号，新增的 Mac 剪贴板与文件发送菜单位于 Windows 端。Android 源码和 Windows WPF 源码分别维护，共用产品图形与版本来源。

## 使用方式

1. 首次在设置中导入专用的 xRemote JSON 组网配置。网络密钥通过 Android Keystore 加密后保存在应用私有目录，不内置在 APK 中。
2. 打开应用即连接私网并按各设备的RDP/VNC协议检查可达性，汇总分母由实际清单动态生成。列表参照 UU 远程：左侧桌面缩略图，中间自定义名称和设备状态，右侧独立详情箭头（点击区宽 60 dp，覆盖卡片高度，图标保持原大小，不加分隔线）。点击卡片连接；点击箭头进入详情：顶部为预览、名称、状态、主要的“连接设备”按钮及轻量“查看登录与连接”入口；设备身份、账户、Windows、CPU、内存、GPU 合并在“设备信息”卡片，“存储空间”单独显示磁盘容量和用量并提供刷新。账户行的“修改”打开凭据设置，省略重复的本机设备名前缀，真实连接保留完整账户，域账户仍保留域名。详情支持系统返回和页内返回。已保存有效凭据时直接连接，未保存时填写 Windows 账户密码并可选择加密记住。次要操作采用透明背景文字按钮，应用内弹窗统一 24 dp 圆角。
   首次成功登录并收到桌面画面后自动保存缩略图，以后每次登录自动更新，离开前台时再保存当前画面。缩略图保持完整比例、存于应用私有目录，不上传；无图时用设备图标占位。它是上次连接的画面。已有设备可通过“设置 → 更新桌面缩略图”逐台生成：使用已保存的凭据和已确认的证书，保存后断开并返回列表；返回可停止整批。缺少凭据、证书待确认或连接失败的设备跳过，需手动连接确认。普通打开列表不会自动登录全部设备。
3. 远程桌面使用横屏沉浸全屏，初始远程分辨率按手机可用横屏比例计算，宽度最多 1920 像素。顶部三个悬浮按钮分别为缩放/还原、会话菜单、显示/隐藏键盘；连接成功后隐藏状态文字，不再显示上下固定工具栏和手势提示。会话菜单提供任务管理器、Windows 开始菜单、恢复完整桌面和断开返回。支持点击、拖动、长按右键、双指缩放和移动、中文输入与常用键盘操作；键盘弹出时保持桌面宽度，可用双指移动查看被遮挡部分。
4. 切到其他应用或锁屏后默认保留连接 2 分钟，可设 1/2/5 分钟。返回应用取消超时；超过时限或点“断开并退出”时释放网络、桌面连接及进程。
5. 设备信息显示 Windows 版本/构建号、上次开机、CPU 型号与核心线程、内存容量、可识别的 GPU。存储空间每块物理磁盘一张小卡片，型号只显示一次，所属分区的盘符、已用/总容量、占用率和进度条集中展示；移除重复的容量、剩余空间文字和普通卷标。跨磁盘分区单独展示且不重复计数，无法匹配的分区保留在“其他分区”。GPU 不显示 RDP 虚拟适配器或无法识别型号的基本显示适配器。容量以 GiB/TiB 显示。
   设备信息按设备长期保存在手机应用私有存储中。打开已有快照的详情直接读缓存；首次无缓存时才自动读取完整资料。Windows 升级或更换硬件后，可通过“设置 → 刷新设备信息 → 全部设备/单台设备”主动更新 Windows、CPU、内存容量和 GPU。全部设备依次更新，显示当前进度并汇总成功/部分更新/失败，某台失败不阻止后续设备；关闭进度窗口仍继续处理。失败字段保留原缓存，已有磁盘数据及其采集时间不变。详情页不放固定信息刷新按钮，存储刷新仍单独调用 `/v1/storage?refresh=true`、仅更新存储卡片与独立缓存。无实时 CPU/内存占用率采样。导入 JSON 仅为配对认证，密钥加密保存且不进入 APK。
   设置按“设备管理、连接与后台、关于应用、退出”分组。分组标题左对齐，组内选项文字向右缩进 12 dp，整行点击范围保持不变。设备管理中依次为账户与密码、刷新设备信息、更新桌面缩略图、设备管理配对；连接与后台中为导入组网配置、后台保留；版本与开源组件归入关于应用；断开并退出单独放在底部并使用红字。保留原有八项操作及圆角、透明背景点击反馈和 48 dp 触控高度，较短屏幕可滚动。
6. “登录与连接”先显示当前远程连接概况，再按登录账户分卡片，默认隐藏无账户的非活动控制台入口。账户省略重复设备名；来源为空时显示“未记录”，已断开记录不根据协议字段推断为本机来源。Windows 会话编号、完整账户和原始来源收进“详细信息”，可展开/收起；刷新在原窗口更新。仅活动远程记录且有服务票据时显示“断开连接”，确认框说明账户和程序保留，结果返回后刷新当前窗口。查看和刷新不建立或断开 RDP。

不注册开机启动，不创建 VPN 接口，不修改 Clash 配置。只在有限的后台保留期间运行带通知的临时服务；不是全天常驻。远程断开不会注销 Windows，也不会终止远端程序。Android 系统或厂商仍可能强行终止应用，真机后台保留行为需要验证。

## 构建

需要 Android SDK 36、JDK 17+、Python 3.11+（依赖准备脚本使用的 file_digest 在 3.11 中提供）、已有专用签名设置。支持 Android 13+、arm64-v8a。

```powershell
.\scripts\build.ps1
```

构建最多使用两个工作线程。签名设置位于当前用户的 `.android/xremote/signing.properties`，密钥不在项目内。首次构建用 `scripts/prepare-native.py` 按固定 URL 与 SHA-256 准备原生库；后续检查已有库的哈希，避免重复下载。依赖与构建缓存不入 Git。

生成文件：`app/build/outputs/apk/release/app-release.apk`。产品交付副本放在原项目的 `dist/`。
