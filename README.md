# xRemote 早期版本开发日志

此归档仅保存 Rev.1–Rev.6 的历史开发说明，不包含 xRemote 应用源码或安装程序。

这些版本最初为本地迭代，没有对应的独立源码快照。本次根据保留的开发记录逐版补录 GitHub Release。GitHub 自动显示的 Source code ZIP/TAR 下载项仅包含本文和 CHANGELOG.md，不代表早期版本源码。

各版功能改动见 CHANGELOG.md，或打开 https://github.com/yuzhounh/xRemote/releases 查看各版条目。Windows 正式安装包与可构建源码从 Rev.7 开始提供；最新正式版仍为 Rev.8。
